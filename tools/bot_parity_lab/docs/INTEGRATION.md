# Integrating an owned scraper/browser

The lab never imports or scans the target project. Integration is a one-function adapter that receives a loopback URL.

```python
from paritylab.clients.base import ClientHookContext

async def run_owned_browser(context: ClientHookContext) -> dict[str, object]:
    browser = await your_browser_factory()
    page = await browser.new_page(ignore_https_errors=True)
    await page.goto(context.url)
    await page.wait_for_function("window.__parityLabReady === true")
    # Use the same navigation, context, profile, proxy and lifecycle code as production.
    await page.evaluate("window.parityLabFinish()")
    await page.wait_for_function("window.__parityLabDone === true")
    await browser.close()
    return {"adapter": "owned-project", "version": "..."}
```

Expose it through an importable module:

```powershell
$env:PARITYLAB_CLIENT_HOOK = "my_package.parity_hook:run_owned_browser"
uv run paritylab run-client project-browser-hook --gate
```

```bash
PARITYLAB_CLIENT_HOOK=my_package.parity_hook:run_owned_browser \
  uv run paritylab run-client project-browser-hook --gate
```

The process exits `2` when the gated client has at least one `hard_bot_signal` or `medium_suspicious` finding. Raw HTTP controls are marked `expected_fail`, so they prove the detector is alive without breaking CI.

## Framework-specific placement

- **Playwright/Patchright:** put the hook after browser/context creation and preserve the actual launch arguments, profile, locale, permissions and proxy settings.
- **Nodriver/Camoufox/Cloak/custom CDP client:** navigate the existing page/tab to `context.url`; do not recreate the browser through the lab.
- **Scrapy/httpx/requests:** call the URL through the real downloader middleware and intentionally expect failure because no browser runtime, resource graph or trusted behavior exists.
- **Botasaurus/Crawl4AI:** call from the framework's browser strategy so its browser lifecycle and request interception remain active.

The adapter URL is generated by the lab and cannot point at a third-party host. `LabConfig` rejects non-loopback bind addresses.
