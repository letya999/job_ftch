# Notice

This project independently implements the published JA3 and JA4 TLS client
fingerprint algorithms from protocol fields. JA3 is associated with Salesforce
and is BSD-3-Clause licensed. JA4 TLS Client Fingerprinting is published by
FoxIO under BSD-3-Clause. No source code from either project is copied here.

The lab does not decode, emulate, or reverse engineer proprietary encrypted
payloads from Akamai, Kasada, DataDome, or similar vendors. The local opaque
payload endpoint records only transport metadata, size, digest, entropy, and
format-shape features for payloads produced by software you own.
