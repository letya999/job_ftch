# JobGroup

**Слой**: domain
**Файл**: `job_ftch/domain/job_group.py`
**Протокол / Базовый класс**: `pydantic.BaseModel`

## Что это

`JobGroup` — это сущность, объединяющая несколько идентичных или очень похожих
вакансий, полученных из разных источников (например, один и тот же пост в трёх
разных Telegram-каналах и на сайте компании).
Группа позволяет избежать
дублирования информации для пользователя и сохраняет историю появления вакансии.

## Поля

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `group_id` | `str` | Уникальный хеш-идентификатор группы. |
| `canonical_job` | `JobRecord` | "Лучшая" запись в группе, выбранная как эталонная. |
| `jobs` | `list[JobRecord]` | Список всех индивидуальных записей вакансий в группе. |
| `source_attributions` | `list` | Список источников с указанием времени и ссылок. |
| `source_count` | `int` | Общее количество уникальных источников в группе. |
| `first_seen_at` | `datetime` | Время самого первого обнаружения вакансии. |
| `last_seen_at` | `datetime` | Время самого последнего обновления вакансии. |
| `lifecycle_status` | `str` | Статус (например, `active`, `archived`). |

## Когда создаётся / откуда берётся

Создаётся в узле `JobAggregationNode` в конце пайплайна.
Узел сопоставляет новую
`JobRecord` с существующими в базе данных или создаёт новую группу.

## Куда идёт после

В `JobPersistenceBackend` для сохранения и обновления состояния групп.
Также
может использоваться в `Sinks`, которые поддерживают группировку (например,
отправка сообщения "Вакансия X найдена ещё в 2 каналах").

## Что с ней нельзя делать / инварианты

1.  Все вакансии в `jobs` должны относиться к одной и той же реальной позиции.
2.  `canonical_job` всегда должна быть одной из записей в списке `jobs`.
3.  `group_id` вычисляется на основе канонических признаков вакансии (компания,
    нормализованный заголовок).

## Связанные сущности

*   `JobRecord` — индивидуальная запись, входящая в группу.
*   `JobPersistenceBackend` — хранилище для поиска и обновления групп.

## Пример

```python
# Пример структуры JobGroup
{
    "group_id": "grp_f5e4d3",
    "source_count": 2,
    "first_seen_at": "2026-06-14T10:00:00Z",
    "canonical_job": { ... },
    "jobs": [
        { "source_name": "channel_a", ... },
        { "source_name": "channel_b", ... }
    ]
}
```
