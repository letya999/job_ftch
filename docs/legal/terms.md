# Правила использования

Разрешены просмотр, поиск, ссылки на источники, небольшие приватные интеграции
и разумное использование read-only API с соблюдением лимитов и кэшированием.
Запрещены обход ограничений, доступ к закрытым данным, нагрузочные атаки,
вредоносные payload, спам, массовые автоматические отклики, impersonation и
нарушение прав третьих лиц. API предоставляется без SLA и может меняться или
отключаться ради безопасности. Злоупотребляющий доступ может быть ограничен.

# Terms of use

Viewing, searching, source links, small private integrations and reasonable
read-only API use are permitted with caching and rate limits. Bypassing
controls, seeking private data, load attacks, malicious payloads, spam, bulk
applications, impersonation and third-party rights violations are prohibited.
The API has no SLA and may change or be disabled for security. Abusive access
may be suspended.
