# Технологический стек job_ftch

## Язык и рантайм
- **Python 3.12+**
- **asyncio** для асинхронного выполнения.

## Управление проектом
- **uv** — для управления зависимостями и виртуальными окружениями.

## Основные зависимости
- `pydantic` (>=2.7) — модели данных и валидация.
- `pydantic-settings` — управление конфигурацией.
- `httpx` — асинхронный HTTP-клиент.
- `selectolax` — быстрый парсинг HTML.
- `telethon` — клиент для работы с Telegram MTProto.
- `rapidfuzz` — нечеткое сравнение строк для дедупликации.
- `openai` + `instructor` — работа с LLM и получение структурированных данных.

## Observability (Наблюдаемость)
- `opentelemetry-api` — стандарт для трейсинга.
- `structlog` — структурированное логирование в JSON.

## Инструменты разработки
- `ruff` — заменяет flake8, black и isort (быстрый линтер и форматировщик).
- `mypy` — статическая проверка типов.
- `pytest` + `pytest-asyncio` — фреймворк для тестирования.
- `bandit` — поиск уязвимостей в коде.

## Почему мы НЕ используем некоторые инструменты
- **Scrapy**: Слишком тяжелый и не является нативно асинхронным в контексте современного asyncio.
- **LangChain**: Избыточная абстракция, создающая привязку к вендору.
- **SQLAlchemy**: Будет добавлена только при необходимости поддержки полноценной БД (например, Postgres).
- **Celery**: На ранних этапах достаточно простого планировщика или asyncio-задач.
